# Aplicação do portfólio

Aplicação React + Vite do portfólio profissional de Matheus Francisco.

## Scripts

- `npm run dev`: ambiente de desenvolvimento
- `npm run lint`: validação estática
- `npm run build`: build de produção
- `npm run deploy`: publicação da pasta `dist` na branch `gh-pages`

Os conteúdos bilíngues ficam em `src/data/copy.js` e os 25 projetos do catálogo em `src/data/portfolio.js`.
