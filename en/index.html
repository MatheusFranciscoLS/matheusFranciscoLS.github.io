Main project

Vardão Central

Management system of a machinery dealership, in daily use

  • Solo project
  • In daily use
  • Started in August 2026
  • Private code

The problem

To answer "which part is it and how much", the counter opened a PDF catalog, a price spreadsheet and an old ERP. A wrong part number led to a return, and sales and finance lived in another system.

What I did

I built the system on my own: I gathered the needs in the store itself, turned them into business rules, designed the architecture and the database, implemented the front end and the API, wrote the tests and handle deployment and maintenance.

What the system does

Counter
Search by part number, name, model or PNC, exploded catalog view and quotes as PDF or via WhatsApp.
Sales
A CRM with a deal board, customer ranking, cross-selling and reactivation of idle customers.
Finance
Sales, purchases and expenses, income statement, cash flow, working capital and ABC analysis.
Inventory
Items to order, shortages, shelves and special part orders for customers.

Business rules the system guarantees

  • A typed part number returns only the exact part and the manufacturer’s official replacement. The AI only chooses within a closed list of parts.
  • The old ERP’s rules were reproduced from its own code, each one with automated tests.
  • The ERP data import runs first as a dry run, requires the expected totals, checks everything after writing and can be undone.
  • Amounts in whole cents: splitting a sale into installments always adds up to the total.

BusinessFlow

Management SaaS for accounting firms

A multi-company platform where the firm tracks clients, finance, income statements, documents, deadlines and support tickets, and each client has its own portal.

What I did

  • Isolation between companies in the back end: every record belongs to a company, and a company cannot see another one’s data.
  • JWT authentication with refresh tokens, access roles (partner and analyst), rate limiting and an audit trail.
  • Bank statement reconciliation (OFX), PDF and CSV reports and an API key for external systems.

In the demo you can browse the executive summary, client portfolio, document vault, income statement, task and tax deadline board, finance, audit trail and the client portal.

Personal project, May to Oct 2026

Industrial IoT Platform

Real-time industrial telemetry

Simulated sensors send readings to a Java API. The React dashboard shows each machine’s temperature, vibration and speed and warns when a limit is exceeded.

What I did

  • REST API in Java 21 and Spring Boot, with Spring Security (JWT), JPA and Flyway migrations on PostgreSQL.
  • Each reading goes through a RabbitMQ queue to a Node.js gateway, which delivers it to the dashboard over Socket.IO. If real time drops, the dashboard falls back to polling the API.
  • Tests on the API (some against a real PostgreSQL), the dashboard and the browser, with CI on GitHub Actions and Docker Compose to run everything.
