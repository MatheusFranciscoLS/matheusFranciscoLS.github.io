# Matheus Francisco — Portfólio Full-Stack

Portfólio profissional de [Matheus Francisco](https://matheusfranciscols.github.io), desenvolvido para apresentar produtos full-stack, projetos de dados, inteligência artificial e a trajetória técnica completa.

## Destaques

- Case principal do CogniVault
- 25 projetos organizados com busca e filtros
- Tema claro e escuro com preferência persistida
- Conteúdo completo em português e inglês
- Layout responsivo, navegação acessível e carregamento otimizado
- Imagem Open Graph própria para compartilhamento

## Stack

React 19, Vite, JavaScript, CSS, Lucide Icons e Formspree.

## Desenvolvimento local

```bash
cd meu-portfolio
npm install
npm run dev
```

Validação:

```bash
npm run lint
npm run build
```

Publicação no GitHub Pages:

```bash
npm run deploy
```
